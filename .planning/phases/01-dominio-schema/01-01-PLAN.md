3. Create `services/schedule-service/internal/domain/schedule.go` with package `domain`. Contents:

Import only `"time"` (no external imports in domain).

Define type `ScheduleType string` with constants:
- `ScheduleTypeCron ScheduleType = "cron"`
- `ScheduleTypeOneShot ScheduleType = "one_shot"`

Define struct `Schedule` with ALL exported fields:
- `ID string`
- `OwnerID string`
- `Name string`
- `Description string`
- `ScheduleType ScheduleType`
- `CronExpr string`
- `RunAt *time.Time`
- `DaysFilter int` (bitmask: 0=all days, Sunday=1<<0=1, Monday=1<<1=2, Tuesday=1<<2=4, Wednesday=1<<3=8, Thursday=1<<4=16, Friday=1<<5=32, Saturday=1<<6=64)
- `Timezone string` (IANA string, default "UTC")
- `Action Action` (from action.go, same package)
- `Enabled bool`
- `CreatedAt time.Time`
- `UpdatedAt time.Time`
- `LastRunAt *time.Time`
- `NextRunAt *time.Time`

Define `NewSchedule(id, ownerID, name, description string, scheduleType ScheduleType, cronExpr string, runAt *time.Time, daysFilter int, timezone string, action Action) (*Schedule, error)`:
- If `name == ""` return `nil, ErrInvalidSchedule`
- If `scheduleType == ScheduleTypeCron && cronExpr == ""` return `nil, ErrMissingCronExpression`
- If `scheduleType == ScheduleTypeOneShot && runAt == nil` return `nil, ErrMissingRunAt`
- If `timezone == ""` set timezone = "UTC"
- Set `Enabled = true`, `CreatedAt = time.Now()`, `UpdatedAt = time.Now()`
- Return the populated Schedule pointer and nil error

Define domain methods:
- `func (s *Schedule) BelongsTo(ownerID string) bool` — returns `s.OwnerID == ownerID` (no wildcard, unlike rules-service; schedules are always user-specific per SCH-03)
- `func (s *Schedule) IsActiveOnDay(day time.Weekday) bool` — if `s.DaysFilter == 0` return true; otherwise `mask := 1 << uint(day); return s.DaysFilter&mask != 0`
- `func (s *Schedule) Disable()` — sets `s.Enabled = false` and `s.UpdatedAt = time.Now()`
- `func (s *Schedule) RecordRun(at time.Time, next *time.Time)` — sets `s.LastRunAt = &at`, `s.NextRunAt = next`, `s.UpdatedAt = at`

Note: errors (ErrInvalidSchedule, ErrMissingCronExpression, ErrMissingRunAt) are defined in errors.go (Plan 02). For this task, add a temporary `var` block at the top of schedule.go with these errors using `errors.New(...)` so the file compiles standalone. Plan 02 will move them to errors.go and remove the duplicates.

IMPORTANT: Do NOT import any external library in this file. Only `"time"` and `"errors"` from stdlib.
